# 🔍 异环OCR助手

**驱动块 + 空幕双模式识别** — 悬浮窗读取属性，按套装权重自动评级。

## ✨ 功能

- **🎯 实时识别** — 无障碍截屏 + PP-OCRv4 识别属性面板
- **🔀 双模式切换** — 悬浮窗顶部「块 / 幕」按钮，一键切换驱动块与空幕
- **📊 自动评级** — 大毕业 / 毕业 / 过渡 / 垃圾
- **🧩 空幕套装识别** — 识别卡带套装名 + 主属性 + 4 条副属性，12 套效果全收录
- **⚖️ 套装独立权重** — 按套装类型（属性输出/通用输出/辅助/防御/生命/治疗）套用不同权重
- **🎨 词条着色** — 高分词条金色显示，其余白色
- **🛠 规则编辑器** — App 内直接新建/编辑规则，不用改文件
- **📤 导入导出** — 规则可导出分享给别人，别人导入即用
- **📌 悬浮窗常驻** — 半透明面板，不遮挡画面，可拖动折叠
- **🤖 自动锁定 / 弃置** — 按勾选的等级自动点击锁定或弃置按钮，两种模式通用
- **🖱 自动遍历点位** — 录一组格子坐标，一键逐格点开、识别、判定，配合手动翻页
- **⏸ 随时暂停 / 停止** — 运行中三键切换为「继续 / 停止 / 结束」，随时可退出
- **✏️ 手动框选** — 框选识别区与按钮位置，自带放大镜，坐标持久保存
- **🚫 不读内存** — 只用截屏权限，不触碰游戏数据

## 🚀 快速开始

### 1. 授权

打开 App，点击三项权限跳转设置：

```
无障碍服务   → 截屏识别
悬浮窗       → 显示控制面板
所有文件访问 → 保存日志
```

### 2. 打开悬浮窗

点「打开悬浮窗」，屏幕出现识别面板。

### 3. 切到游戏

顺序很重要：

```
打开悬浮窗 → 按 Home 退到桌面 → 启动游戏 → 点「开始」
```

App 在前台时截到的是 App 自己，读不出内容。

### 4. 首次使用建议框选

点「框选」，单指拖框住右侧属性面板，松手生效。坐标会记住。

### 5. 切换模式

悬浮窗标题栏右侧有个「块」按钮，点一下变「幕」，即进入空幕模式；再点回「块」切回驱动块。

```
块  →  驱动块模式（识别驱动块副属性）
幕  →  空幕模式（识别卡带套装 + 主属性 + 副属性）
```

切到空幕模式后首次使用，建议在设置里框选一次「空幕面板」。

## 🖱 自动遍历点位

按顺序自动点开一页里的每个格子，识别后自动判定并上锁/弃置。

### 1. 录制点位

悬浮窗「设置」→「录制点位」，在屏幕上依次点出每个格子的位置，点「完成」保存。

点位会按点击顺序执行，顺序即是遍历顺序。

### 2. 开始执行

悬浮窗「开始」→「设置」→「执行本页」，程序会：

```
点第 1 格 → 等卡片弹出 → 截图 OCR → 评级 → 自动上锁/弃置 → 点第 2 格 → …
```

整页跑完后自动停下，状态栏提示「本页已完成」。

### 3. 翻页

**当前为手动翻页**：跑完一页后，手动在游戏里翻到下一页，再点一次「执行本页」即可。

自动翻页功能暂时停用，原因是背包数量会变化，翻页后无法可靠判断是否真的到了新的一页。

### 4. 暂停与停止

| 按钮 | 作用 |
|------|------|
| **暂停** | 停住当前流程，保留进度 |
| **继续** | 从暂停处接着跑 |
| **停止** | 彻底结束本次执行 |

暂停状态下再点「暂停」等于停止。按音量下键也可以暂停。

> 💡 自动化总开关在设置页，关闭后既不自动锁定，也不自动遍历。悬浮窗里的「自动切换」与它是同一份配置。

## ⚖️ 评级规则

### 判定顺序

按顺序匹配，命中即停：

| # | 条件 | 等级 |
|---|------|------|
| 1 | 双爆 + 攻% + 增伤 | 大毕业 |
| 2 | 双爆 + 大攻击 + 小攻 | 毕业 |
| 3 | 双爆 + (环合或倾陷) + 大攻击 | 毕业 |
| 4 | 双爆 + 任意大攻击 | 毕业 |
| 5 | 双爆（无大攻击） | 过渡 |
| 6 | 单爆 + 大攻击 | 过渡 |
| 7 | 其余 | 垃圾 |

### 术语

| 词 | 含义 |
|---|---|
| **双爆** | 暴击率 + 暴击伤害 |
| **单爆** | 只有其中一个 |
| **大攻击** | 攻击力百分比 或 通用伤害增强 |
| **小攻** | 攻击力（整数版） |

### 权重

| 词条 | 权重 | 词条 | 权重 |
|------|------|------|------|
| 暴击率 | 20 | 生命值百分比 | 4 |
| 暴击伤害 | 20 | 防御力百分比 | 3 |
| 攻击力百分比 | 14 | 生命值 | 2 |
| 通用伤害增强 | 14 | 防御力 | 1 |
| 攻击力 | 8 | 环合强度 | 0 |
|  |  | 倾陷强度 | 0 |

总分 = 权重之和 + 双爆加成 3

> ⚠️ 环合/倾陷权重为 0 但能升档，会出现分数倒挂：
> `双爆+攻%+环合 = 57分 → 毕业`，`双爆+攻%+生命% = 61分 → 毕业`

## 🎴 空幕评级

空幕是**总分制**，与驱动块的逻辑匹配不同。

### 计算方式

```
总分 = 主属性分 + 四条副属性分之和 + 双爆加成
等级 = 总分 ÷ 该套装满分，按比例查档
```

### 硬性前提：主属性必须有效

主属性在**该套装的权重表中权重 > 0** 才算有效。

- 有效 → 正常算分
- 无效 → 直接判「垃圾」，副属性不再计分、不着色

比如给暗套（迪亚波罗斯）刷出「倾陷强度」主属性，权重为 0，直接垃圾。

### 等级门槛

| 等级 | 占满分比例 |
|---|---|
| 大毕业 | ≥ 84% |
| 毕业 | ≥ 67% |
| 过渡 | ≥ 43% |
| 垃圾 | < 43% |

### 套装分类与权重档

12 套卡带按效果分成 6 类，各用一套独立权重：

| 权重档 | 套装 | 满分 | 主属性最优 |
|---|---|---|---|
| 属性输出 | 迪亚波罗斯(暗)、真红·双生蝶(咒)、森林萤火之心(灵)、失落光芒(光)、街头拳王(相)、恶魔之血·诅咒(魂)、静谧山庄(心灵) | 105 | 本命属性伤害 32 |
| 通用输出 | 影之信条 | 103 | 攻击力百分比 34 |
| 辅助 | 音速蓝刺猬 | 94 | 环合/倾陷 30 |
| 防御 | 守卫王国 | 100 | 防御力百分比 34 |
| 生命 | 小小大冒险 | 92 | 生命值百分比 34 |
| 治疗 | 缇娅的夜间酒馆 | 89 | 治疗加成 34 |

权重设计原则：**套装效果给什么，对应词条权重就最高**。套装效果完全不含的词条，权重为 0。

| 街头拳王 | 相 | 相属性伤害 +10% | 暴击率 +14%，触发反应再 +14%＝28% |
| 恶魔之血·诅咒 | 魂 | 魂属性伤害 +10% | 伤害 +18%，打浸染/黯星变 +36% |

### 词条着色

副词条按权重分两档：

- **金色** — 权重 ≥ 该权重档最高值的一半
- **白色** — 其余

驱动块同理，按 `general.json` 的权重表判断。

## 🛠 自定义规则

**不用改代码，App 内直接编辑。**

规则分两类：驱动块规则、空幕规则，各自独立管理。

### 入口

主界面「当前规则」卡片右上角有「规则 ›」，点进去就是规则管理页。

徽章会显示当前用的是 **内置** 还是 **自定义**。

### 规则管理页

```
规则管理                    完成
点规则名切换，长按删除

[驱动块] [空幕]

● 通用规则  v1  内置          [复制]
                               [导出]
  我的规则  v2
  general_我的规则.json        [编辑]
                               [导出]

[新建]  [导入]
```

| 操作 | 方式 |
|---|---|
| **切换** | 点规则行，立即生效（悬浮窗开着也行） |
| **删除** | 长按规则行 |
| **编辑** | 点「编辑」按钮 |
| **复制** | 内置规则点「复制」，生成可编辑副本 |
| **导出** | 点「导出」，文件保存到 `/sdcard/HollowAffix/export/`，可分享 |
| **导入** | 点底部「导入」，选 JSON 文件 |

### 驱动块规则编辑器（5 页）

| 页 | 可编辑内容 |
|---|---|
| **基本** | 规则名（必填）、作者、描述、版本、双爆加成、兜底等级 |
| **权重** | 11 个词条权重，填 ≥ 0 的整数 |
| **判定** | 规则列表，可增删、调整顺序（↑↓）；每条可设等级、编辑条件 |
| **组** | 组列表，可增删、改名、编辑成员 |
| **等级** | 等级列表，可改名、改颜色（#RRGGBB） |

**判定条件怎么填**：对话框里有三块

```
必须同时满足   ☑ 双爆   ☑ 攻击力百分比   ☐ 通用伤害增强
至少满足其一   ☐ 环合强度   ☐ 倾陷强度
词条数下限     不少于 [ 4 ] 条（0 = 不限）
```

**匹配规则**：

| 写法 | 含义 |
|---|---|
| 组名「双爆」 | 组内**全部**命中 |
| 组名「单爆」 | 组内**恰好 1 个**命中 |
| 其他组名 | 组内**任意 1 个**命中 |
| 具体词条名 | 必须有该词条 |

### 空幕规则编辑器（6 页）

| 页 | 可编辑内容 |
|---|---|
| **基本** | 规则名（必填）、作者、描述、版本、双爆加成 |
| **等级** | 增删等级、改名、改颜色、**改占比门槛** |
| **权重档** | 增删权重档、改显示名、改满分 |
| **套装** | 增删套装、绑定权重档、指定本命属性、编辑详情 |
| **主属性** | 当前权重档的 15 项主属性权重 |
| **副属性** | 当前权重档的 11 项副属性权重 |

**等级门槛**必须从高到低递减，例如：

```
大毕业  ≥ 0.84
毕业    ≥ 0.67
过渡    ≥ 0.43
垃圾    ≥ 0
```

**套装详情**可填：名称、别名（用于 OCR 容错，逗号分隔）、属性、类型、2 件套效果、4 件套效果、备注。

### 必填项校验

保存和导入都会检查，有问题会列出全部错误：

```
无法保存
发现 2 个错误：
[错误] 规则名：不能为空
[错误] 规则3/条件：「双爆」既不是词条也不是组
```

| 检查项 | 规则 |
|---|---|
| 规则名 | 不能为空 |
| 判定规则 | 至少 1 条（驱动块） |
| 每条规则的等级 | 不能为空 |
| 每条规则的条件 | 至少设一个 |
| 条件引用 | 必须是合法词条或已定义的组 |
| 组 | 组名非空、至少 1 个成员、成员必须合法 |
| 颜色 | 必须 `#RRGGBB` |
| 空幕等级门槛 | 0~1 之间且必须递减 |
| 空幕权重档满分 | 大于 0 |
| 空幕套装 | 权重档必须存在；本命属性必须合法 |

警告不阻止保存（比如某词条未设权重，按 0 处理）。


## 🔧 技术实现

| 环节 | 方案 |
|------|------|
| 截屏 | `AccessibilityService.takeScreenshot()` |
| OCR | PP-OCRv4 (det + rec) + onnxruntime-android |
| 文本检测 | DB 算法：置信度过滤 + unclip 外扩 + 去重 |
| 字典 | 6625 字符（对齐 RapidOCR） |
| 评级 | 数据驱动，规则在 JSON |

### OCR 容错

- `%` 误读为 `9` / `g` / `q` → 自动纠正
- `提升` 误读为 `堤升` → 关键字模糊匹配
- 小数点丢失 → 靠小数点判断百分比形态
- 文字截断 → DB unclip 外扩补全

## 📦 构建

### 1. 下载模型

三个 onnx 模型（15.5MB）未放入仓库，从 [RapidOCR Releases](https://github.com/RapidAI/RapidOCR/releases) 下载后放入 `app/src/main/assets/`：

```
ch_PP-OCRv4_det_infer.onnx           4.5 MB
ch_PP-OCRv4_rec_infer.onnx          10.4 MB
ch_ppocr_mobile_v2.0_cls_infer.onnx  0.6 MB
```

字典 `ppocr_keys.txt` 已在仓库中。

### 2. 编译

```bash
git clone https://github.com/a2006-dev/HollowAffix.git
cd HollowAffix
./gradlew assembleDebug
```

或使用 AndroidIDE 直接打开项目构建。

### 3. 签名（可选）

在项目根目录创建 `keystore.properties`：

```properties
storeFile=your-key.p12
storePassword=你的密码
keyAlias=你的别名
```
