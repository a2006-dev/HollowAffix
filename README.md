# 异环OCR助手

《异环》空幕 · 驱动块实时识别工具

悬浮窗实时读取驱动块副属性，按规则模板自动评级。不用切界面，一边刷一边看。

## 它做什么

刷驱动块时，最烦的是来回切界面判断这件值不值得留。

这个工具在你刷的时候就把答案摆在屏幕上：

```
┌─────────────────────┐
│ 通用规则         ─ ×│
│ 12轮 850ms          │
│                     │
│ 毕业           61分 │
│ 双爆+攻%            │
│ · 攻击力 3.75%      │
│ · 暴击率 3%         │
│ · 暴击伤害 6%       │
│ · 环合强度 18       │
│                     │
│ [开始][暂停][框选]  │
└─────────────────────┘
```

等级一眼看清：**大毕业** / **毕业** / **过渡** / **垃圾**，颜色各不相同。

---

## 特点

**纯手机端** — 不用连电脑，不用装插件，一个 APK 装完就用。

**不读内存，不抓包** — 只用系统的截屏权限读屏幕，不碰游戏数据。

**规则可换** — 判定逻辑写在 JSON 里，不改代码就能换一套规则。

**悬浮窗显示规则名** — 屏幕角落标着当前用哪套规则，不会搞混。

## 怎么用

### 1. 给三个权限

| 权限 | 干什么 |
|---|---|
| 无障碍服务 | 截屏识别 |
| 悬浮窗 | 显示面板 |
| 所有文件访问 | 存识别日志 |

点对应条目会跳到设置页。

### 2. 打开悬浮窗，然后切到游戏

**注意顺序**：

1. 打开 App → 点「打开悬浮窗」
2. **按 Home 键退到桌面**
3. 启动游戏，选中要看的驱动块
4. 点悬浮窗上的「开始」

识别的是当前屏幕内容。App 还在前台时，截到的是 App 自己，读不出东西。

### 3. 第一次用建议框选一次

点「框选」，用一根手指拖一个框框住右侧属性面板，松手生效。坐标会记住。

## 评级规则

默认「通用规则」，四档判定：

```
1. 双爆 + 攻% + 增伤              → 大毕业
2. 双爆 + 大攻击 + 小攻            → 毕业
3. 双爆 + (环合|倾陷) + 大攻击     → 毕业
4. 双爆 + 任意大攻击               → 毕业
5. 双爆（无大攻击）                → 过渡
6. 单爆 + 大攻击                   → 过渡
7. 其余                            → 垃圾
```

**术语**

- **双爆** = 暴击率 + 暴击伤害 都有
- **单爆** = 只有其中一个
- **大攻击** = 攻击力百分比 或 通用伤害增强
- **小攻** = 攻击力（整数那条）

**权重**

| 词条 | 权重 | 词条 | 权重 |
|---|---|---|---|
| 暴击率 | 20 | 生命值百分比 | 4 |
| 暴击伤害 | 20 | 防御力百分比 | 3 |
| 攻击力百分比 | 14 | 生命值 | 2 |
| 通用伤害增强 | 14 | 防御力 | 1 |
| 攻击力 | 8 | 环合/倾陷强度 | 0 |

总分 = 词条权重之和 + 双爆加成 3

### 一个反直觉的地方

环合强度和倾陷强度**权重是 0**，但能让评级升档（规则第 3 条）。

```
双爆 + 攻% + 环合  = 57分 → 毕业
双爆 + 攻% + 生命% = 61分 → 毕业
```

分数低的反而等级高。这是原设计有意为之，不是 bug。

## 自定义规则

规则文件在 `app/src/main/assets/rules/general.json`。

```json
{
  "name": "通用规则",
  "author": "你的名字",
  "version": 1,
  "weights": { "暴击率": 20, "暴击伤害": 20, "攻击力百分比": 14 },
  "groups": {
    "双爆": ["暴击率", "暴击伤害"],
    "单爆": ["暴击率", "暴击伤害"],
    "大攻击": ["攻击力百分比", "通用伤害增强"]
  },
  "rules": [
    { "grade": "大毕业", "desc": "双爆+攻%+增伤",
      "require": ["双爆", "攻击力百分比", "通用伤害增强"] },
    { "grade": "毕业", "desc": "双爆+大攻击",
      "require": ["双爆", "大攻击"] }
  ],
  "fallback": "垃圾",
  "colors": { "大毕业": "#FF4D4D", "毕业": "#FFB300" }
}
```

改判定逻辑只改 `rules` 数组，**按顺序匹配，命中即停**。

### 匹配写法

| 写法 | 含义 |
|---|---|
| `require: ["双爆"]` | 两个暴击词条必须都有（特殊逻辑）|
| `require: ["单爆"]` | 只能有其中一个（特殊逻辑）|
| `require: ["大攻击"]` | 组里任意一个命中就行 |
| `require: ["攻击力"]` | 必须有这个具体词条 |
| `requireAny: [...]` | 至少满足其中一项 |
| `minCount: 4` | 词条总数不少于 4 |

## 技术实现

| 环节 | 方案 |
|---|---|
| 截屏 | `AccessibilityService.takeScreenshot()`（无授权弹窗，不产生录像）|
| OCR | PP-OCRv4（det + rec），onnxruntime-android 推理 |
| 文本检测 | DB 算法：置信度过滤 + unclip 外扩 + 去重 |
| 字符字典 | 6625 字，对齐 RapidOCR 官方 |
| 评级 | 数据驱动，规则在 JSON 里 |

**OCR 容错**：

- `%` 被读成 `9` / `g` / `q` → 自动纠正
- `提升` 被读成 `堤升` → 关键字模糊匹配
- 小数点被吞 → 靠小数点判断百分比形态
- 文字被切断 → DB 的 unclip 外扩保证完整

## 编译

需要 AndroidIDE（或 Android Studio）。

### 模型文件（仓库里没有）

三个 onnx 模型共 15.5MB，没放进仓库。到 [RapidOCR 模型库](https://github.com/RapidAI/RapidOCR/releases) 下载后放进 `app/src/main/assets/`：

```
ch_PP-OCRv4_det_infer.onnx           (4.5 MB)
ch_PP-OCRv4_rec_infer.onnx           (10.4 MB)
ch_ppocr_mobile_v2.0_cls_infer.onnx  (0.6 MB)
```

字典 `ppocr_keys.txt` 已在仓库里。

### 签名

`app/build.gradle` 从 `keystore.properties` 读签名：

```properties
storeFile=your-key.p12
storePassword=你的密码
keyAlias=你的别名
keyPassword=你的密码
```

**没有这个文件也能编译 debug 版**。

### 输出

```
/sdcard/HollowAffix/
├── trace.txt        执行过程
├── ocr_cards.txt    识别结果
└── region.txt       区域变更记录
```

## 已知限制

- **只支持横屏游戏画面**，竖屏时提示「请切到游戏」
- **默认坐标基于 3168×1440**，其他分辨率请先框选一次
- **不识别主属性**，只看副属性判定
- **环合/倾陷的数值大小不影响判定**，只看有没有

## 关于《异环》

本工具是第三方辅助，通过识别玩家自己的屏幕内容提供信息参考。

- 不修改游戏文件
- 不读写游戏数据
- 不自动操作游戏
- 不介入任何游戏内交互

请遵守游戏的用户协议。使用本工具产生的任何后果由使用者自行承担。
