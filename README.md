# 🔍 异环OCR助手

**驱动块 + 空幕双模式识别** — 悬浮窗读取属性，按套装权重自动评级。

## ✨ 功能

- **🎯 实时识别** — 无障碍截屏 + PP-OCRv4 识别属性面板
- **🔀 双模式切换** — 悬浮窗顶部「块 / 幕」按钮，一键切换驱动块与空幕
- **📊 自动评级** — 大毕业 / 毕业 / 过渡 / 垃圾
- **🧩 空幕套装识别** — 识别卡带套装名 + 主属性 + 4 条副属性，12 套效果全收录
- **⚖️ 套装独立权重** — 按套装类型（属性输出/通用输出/辅助/防御/生命/治疗）套用不同权重
- **🎨 词条着色** — 高分词条金色显示，其余白色
- **📌 悬浮窗常驻** — 半透明面板，不遮挡画面，可拖动折叠
- **🧩 规则可换** — 判定逻辑写在 JSON 里，改文件就能换规则
- **🏷 规则名显示** — 悬浮窗顶部标注当前规则
- **🤖 自动锁定 / 弃置** — 按勾选的等级自动点击锁定或弃置按钮，两种模式通用
- **✏️ 手动框选** — 框选识别区与按钮位置，自带放大镜，坐标持久保存
- **🚫 不读内存** — 只用截屏权限，不触碰游戏数据

## 🚀 快速开始

### 1. 授权

打开 App，点击三项权限跳转设置：

```
无障碍服务   → 截屏识别
悬浮窗       → 显示控制面板
所有文件访问 → 保存日志
```

### 2. 打开悬浮窗

点「打开悬浮窗」，屏幕出现识别面板。

### 3. 切到游戏

顺序很重要：

```
打开悬浮窗 → 按 Home 退到桌面 → 启动游戏 → 点「开始」
```

App 在前台时截到的是 App 自己，读不出内容。

### 4. 首次使用建议框选

点「框选」，单指拖框住右侧属性面板，松手生效。坐标会记住。

### 5. 切换模式

悬浮窗标题栏右侧有个「块」按钮，点一下变「幕」，即进入空幕模式；再点回「块」切回驱动块。

```
块  →  驱动块模式（识别驱动块副属性）
幕  →  空幕模式（识别卡带套装 + 主属性 + 副属性）
```

切到空幕模式后首次使用，建议在设置里框选一次「空幕面板」。

## ⚖️ 评级规则

### 判定顺序

按顺序匹配，命中即停：

| # | 条件 | 等级 |
|---|------|------|
| 1 | 双爆 + 攻% + 增伤 | 大毕业 |
| 2 | 双爆 + 大攻击 + 小攻 | 毕业 |
| 3 | 双爆 + (环合或倾陷) + 大攻击 | 毕业 |
| 4 | 双爆 + 任意大攻击 | 毕业 |
| 5 | 双爆（无大攻击） | 过渡 |
| 6 | 单爆 + 大攻击 | 过渡 |
| 7 | 其余 | 垃圾 |

### 术语

| 词 | 含义 |
|---|---|
| **双爆** | 暴击率 + 暴击伤害 |
| **单爆** | 只有其中一个 |
| **大攻击** | 攻击力百分比 或 通用伤害增强 |
| **小攻** | 攻击力（整数版） |

### 权重

| 词条 | 权重 | 词条 | 权重 |
|------|------|------|------|
| 暴击率 | 20 | 生命值百分比 | 4 |
| 暴击伤害 | 20 | 防御力百分比 | 3 |
| 攻击力百分比 | 14 | 生命值 | 2 |
| 通用伤害增强 | 14 | 防御力 | 1 |
| 攻击力 | 8 | 环合强度 | 0 |
|  |  | 倾陷强度 | 0 |

总分 = 权重之和 + 双爆加成 3

> ⚠️ 环合/倾陷权重为 0 但能升档，会出现分数倒挂：
> `双爆+攻%+环合 = 57分 → 毕业`，`双爆+攻%+生命% = 61分 → 毕业`

## 🎴 空幕评级

空幕是**总分制**，与驱动块的逻辑匹配不同。

### 计算方式

```
总分 = 主属性分 + 四条副属性分之和 + 双爆加成
等级 = 总分 ÷ 该套装满分，按比例查档
```

### 硬性前提：主属性必须有效

主属性在**该套装的权重表中权重 > 0** 才算有效。

- 有效 → 正常算分
- 无效 → 直接判「垃圾」，副属性不再计分、不着色

比如给暗套（迪亚波罗斯）刷出「倾陷强度」主属性，权重为 0，直接垃圾。

### 等级门槛

| 等级 | 占满分比例 |
|---|---|
| 大毕业 | ≥ 84% |
| 毕业 | ≥ 67% |
| 过渡 | ≥ 43% |
| 垃圾 | < 43% |

### 套装分类与权重档

12 套卡带按效果分成 6 类，各用一套独立权重：

| 权重档 | 套装 | 满分 | 主属性最优 |
|---|---|---|---|
| 属性输出 | 迪亚波罗斯(暗)、真红·双生蝶(咒)、森林萤火之心(灵)、失落光芒(光)、街头拳王(相)、恶魔之血·诅咒(魂)、静谧山庄(心灵) | 105 | 本命属性伤害 32 |
| 通用输出 | 影之信条 | 103 | 攻击力百分比 34 |
| 辅助 | 音速蓝刺猬 | 94 | 环合/倾陷 30 |
| 防御 | 守卫王国 | 100 | 防御力百分比 34 |
| 生命 | 小小大冒险 | 92 | 生命值百分比 34 |
| 治疗 | 缇娅的夜间酒馆 | 89 | 治疗加成 34 |

权重设计原则：**套装效果给什么，对应词条权重就最高**。套装效果完全不含的词条，权重为 0。

### 词条着色

副词条按权重分两档：

- **金色** — 权重 ≥ 该权重档最高值的一半
- **白色** — 其余

驱动块同理，按 `general.json` 的权重表判断。

## 🧩 自定义规则

规则文件：`app/src/main/assets/rules/general.json`

```json
{
  "name": "通用规则",
  "author": "AJX",
  "version": 1,
  "weights": {
    "暴击率": 20,
    "暴击伤害": 20,
    "攻击力百分比": 14
  },
  "groups": {
    "双爆": ["暴击率", "暴击伤害"],
    "单爆": ["暴击率", "暴击伤害"],
    "大攻击": ["攻击力百分比", "通用伤害增强"]
  },
  "rules": [
    {
      "grade": "大毕业",
      "desc": "双爆+攻%+增伤",
      "require": ["双爆", "攻击力百分比", "通用伤害增强"]
    },
    {
      "grade": "毕业",
      "desc": "双爆+大攻击",
      "require": ["双爆", "大攻击"]
    }
  ],
  "fallback": "垃圾",
  "colors": {
    "大毕业": "#FF4D4D",
    "毕业": "#FFB300"
  }
}
```

### 匹配写法

| 写法 | 含义 |
|------|------|
| `require: ["双爆"]` | 两词条必须都有（特殊逻辑） |
| `require: ["单爆"]` | 恰好命中一个（特殊逻辑） |
| `require: ["大攻击"]` | 组内任一命中 |
| `require: ["攻击力"]` | 必须有该词条 |
| `requireAny: [...]` | 至少满足一项 |
| `minCount: 4` | 词条数不少于 N |

## 🔧 技术实现

| 环节 | 方案 |
|------|------|
| 截屏 | `AccessibilityService.takeScreenshot()` |
| OCR | PP-OCRv4 (det + rec) + onnxruntime-android |
| 文本检测 | DB 算法：置信度过滤 + unclip 外扩 + 去重 |
| 字典 | 6625 字符（对齐 RapidOCR） |
| 评级 | 数据驱动，规则在 JSON |

### OCR 容错

- `%` 误读为 `9` / `g` / `q` → 自动纠正
- `提升` 误读为 `堤升` → 关键字模糊匹配
- 小数点丢失 → 靠小数点判断百分比形态
- 文字截断 → DB unclip 外扩补全

## 📦 构建

### 1. 下载模型

三个 onnx 模型（15.5MB）未放入仓库，从 [RapidOCR Releases](https://github.com/RapidAI/RapidOCR/releases) 下载后放入 `app/src/main/assets/`：

```
ch_PP-OCRv4_det_infer.onnx           4.5 MB
ch_PP-OCRv4_rec_infer.onnx          10.4 MB
ch_ppocr_mobile_v2.0_cls_infer.onnx  0.6 MB
```

字典 `ppocr_keys.txt` 已在仓库中。

### 2. 编译

```bash
git clone https://github.com/a2006-dev/HollowAffix.git
cd HollowAffix
./gradlew assembleDebug
```

或使用 AndroidIDE 直接打开项目构建。

### 3. 签名（可选）

在项目根目录创建 `keystore.properties`：

```properties
storeFile=your-key.p12
storePassword=你的密码
keyAlias=你的别名
keyPassword=你的密码
```

无此文件时自动跳过 release 签名，不影响 debug 构建。

## ⚠️ 已知限制

| 限制 | 说明 |
|------|------|
| **仅横屏** | 竖屏时状态栏提示「请切到游戏」 |
| **默认坐标 3168×1440** | 其他分辨率需框选一次 |
| **两种模式共用按钮坐标** | 空幕与驱动块的锁定/弃置按钮若位置不同，需实际验证 |
| **空幕面板需可完整框选** | 框选区域过小会切断文字，导致副属性漏识别 |
| **不识别主属性** | 仅按副属性判定 |
| **环合/倾陷不看数值** | 只判断是否存在 |
| **自动操作无状态检测** | 依靠卡片内容变化去重，已锁的卡再次识别到可能被重复点击 |
